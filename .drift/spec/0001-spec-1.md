# Spec — 代码块/引用块折行的精确约束

## 目标文件：`_sass/_base.scss`

### 1. `pre` 规则（当前约第 195-212 行）
在现有属性基础上新增，最终应包含：
```scss
pre {
    font-family: $mono-font-family;
    font-size: 14px;
    line-height: 1.65;
    padding: 20px 22px;
    overflow-x: auto;           /* 保留：兜底 */
    white-space: pre-wrap;      /* 新增：超宽行折行 */
    overflow-wrap: break-word;  /* 新增：打断长 hex/hash */
    word-break: break-word;     /* 新增：旧浏览器兼容 */
    border-radius: 6px;
    background-color: $ink-code-bg;
    box-shadow: 0 10px 26px -16px rgba(#000, 0.55);

    > code { /* 保持现状不变 */ }
}
```

### 2. `blockquote` 规则（当前约第 165-179 行）
新增一行：
```scss
blockquote {
    /* ...现有属性... */
    overflow-wrap: break-word;  /* 新增：显式加固 */
}
```

## 约束（必须满足）
- 仅改 `_sass/_base.scss`；**不改** `_posts/2017-05-11-7daystalk.md`，**不改** `_site` 产物（由 build 生成）。
- 保留 `pre > code` 的现有 reset（`background:none; color:inherit; padding:0; font-size:1em;`）不变。
- 不引入 `body { overflow-x: hidden }`。
- 不改变语法高亮 `_syntax-highlighting.scss`。

## 期望结果
- 代码块内 431 字符 hex 等超长行自动折行，无内部横向滚动条；页面无横向滚动。
- 短代码行、缩进、空行、ASCII 图（短行）渲染不变。
- 引用块长串折行正常。

## 验收清单
1. `bundle exec jekyll build` 成功，无 Sass 错误。
2. `_site/css/main.css` 的 `pre` 规则含 `white-space: pre-wrap; overflow-wrap: break-word; word-break: break-word;`；`blockquote` 含 `overflow-wrap: break-word;`。
3. 浏览器实测：代码块无横向滚动条、长 hex 折行；视觉（暗底、圆角、阴影、高亮）不回归。
