# ADR — 让代码块折行，消除横向滚动条（方案 A）

## 决策
采用**方案 A**：主题级 CSS 让代码块折行，并在引用块上显式加固折行。

## 理由
- 根因是代码块内超长不可断行串（最长 431 字符 hex）在 `white-space: pre` + `overflow-x: auto` 下产生内部横向滚动条，不满足"看全内容、无需左右滚动"的目标。
- `white-space: pre-wrap` 仅对超宽行折行，短行、缩进、空行、ASCII 图（短行）均不受影响，风险低。
- 方案 B 无法消除代码块内部滚动，排除；方案 C 改 Markdown 侵入性强且对超长 hex 不可行，排除。

## 落地（决策）
1. `_sass/_base.scss` 的 `pre` 规则：
   - 保留 `overflow-x: auto` 作兜底；
   - 新增 `white-space: pre-wrap;`（超宽行折行）；
   - 新增 `overflow-wrap: break-word;`（打断长 hex/hash token）；
   - 新增 `word-break: break-word;`（旧浏览器兼容）。
2. `blockquote` 规则显式加 `overflow-wrap: break-word;`（虽已从 `.post-content` 继承，但显式声明更稳）。

## 权衡
- 优点：一次修复、全站复用、零 Markdown 改动、彻底消除横向滚动条。
- 代价：`pre-wrap` 使极个别超宽 ASCII 图折行（本文未发现），属可接受且符合诉求。

## 变更文件
- `_sass/_base.scss`（`pre` 与 `blockquote` 规则）
